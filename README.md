# EPIC 排課系統

EPIC 禪藝實相人文空間的課務排程系統。課表、師資、場地、報名、衝突檢查，
外加一條把 LINE 課務群訊息變成「待審課務提案」的管線。

```
LINE 課務群 ─┬─ B 匯出 .txt ──→ LINE群組同步 ──┐
             └─ A 官方帳號 bot ────────────────┤
                                               ├→ Apps Script 後端 ──→ Google 試算表
                                               │        │
                                               │   萃取待審提案
                                               │
GitHub Pages 網站 ←────── 密碼驗證（後端驗）────┘
```

---

## 檔案

| 路徑 | 做什麼 |
|---|---|
| `index.html` `app.js` `style.css` | 網站本體，發布到 GitHub Pages |
| `config.js` | 後端網址。留空＝離線預覽模式 |
| `apps-script/Code.gs` | 後端：資料表 CRUD、密碼、課表展開、衝突檢查、報名 |
| `apps-script/Extract.gs` | LINE 訊息 → 課務提案的**唯一**一份萃取規則 |
| `apps-script/LineWebhook.gs` | 路徑 A：bot webhook 接收器 |
| `line/上傳到排課系統.js` | 路徑 B：把倉庫裡的訊息送進後端 |
| `line/測試萃取規則.js` | 直接載入 `Extract.gs` 跑測試（12 個案例） |
| `資料/seed-2026-10.json` | 2026.10 月曆印刷稿的逐格轉錄，含 6 條待確認 |
| `LINE接入指南.md` | 兩條 LINE 路徑的完整設定步驟 |

## 密碼

兩級，都在**試算表的「設定」分頁**，隨時可改，不必重新部署。

| 密碼 | 能做什麼 |
|---|---|
| 檢視密碼 `baoyan2026` | 看課表、看衝突、看提案 |
| 排課密碼 `admin2026` | 以上全部，再加新增／修改／刪除、處理 LINE 提案 |

密碼在**後端驗**，不是前端比字串——看網頁原始碼看不到密碼。

## 資料模型

- **固定週課**　每週固定開的課（星期＋時段）
- **單次活動**　有明確日期的活動、法會、展覽檔期
- **異動**　　　某一天對某一門固定週課的例外：停課／改時間／換場地／代課
- **報名**　　　誰報了哪天哪堂，超過人數上限自動轉候補
- **待確認**　　資料本身互相矛盾、系統拒絕自行決定的事項
- **課務提案**　LINE 訊息萃取出來的待審異動

月曆上看到的每一堂，是「固定週課 ＋ 單次活動 ＋ 異動」在該日展開的結果。

## 衝突檢查查什麼

| 類型 | 條件 |
|---|---|
| 場地重複 | 同一天、同一場地、時段重疊（線上課程不算） |
| 師資撞堂 | 同一天、同一位老師、時段重疊 |
| 法會期間 | 固定週課排在多日法會的日期範圍內 → 提醒確認是否停課 |

現有資料已經抓到一筆真的：10/11 兒童哲學與心力量（09:00–17:00）
與見輝法師企業專班（09:30–14:00）同場地重疊。

## 本機預覽

```bash
node 本機預覽.js
```

開 <http://localhost:4321>。`config.js` 的 `API` 留空時會進離線預覽模式，
直接讀 `seed.json`，只能看不能存——後端還沒好的時候可以先檢查畫面。

> `seed.json` 的內容就是那張公開發送的月曆印刷稿，沒有個資。
> 真正的課務資料與 LINE 原文都在試算表裡，要密碼才拿得到。

## 測試

```bash
node line/測試萃取規則.js
```

直接把 `apps-script/Extract.gs` 載進 Node 跑，測的就是上線那一份，不是另寫的模擬版。
12 個案例涵蓋停課／改期／代課／加開／人數／換場地，以及「大家早安」「[貼圖]」
這類該被略過的閒聊。

## 鐵律

**LINE 訊息永遠不會自動改課表。**

萃取出來的一律是「待審提案」。要真的動到課表，必須有人在後台按套用，
而且按下去只是把異動表單預填好，還要再按一次儲存。

理由很實際：群裡有人問「這週三要不要停課？」是問句，有人說「上次不是說停課了嗎」
是回憶，有人在轉貼別的群的訊息。機器用關鍵字分不出來，所以不給它權限。

**資料有矛盾時，系統不自己選答案。**

月曆印刷稿本身有幾處前後不一致（法會日期、AI 班開始時間），
這些都進了「待確認」分頁，標上證據與該問誰，而不是挑一個看起來比較對的填進去。

## 改版後記得加版本號

`index.html` 底部載入 `config.js?v=N`、`app.js?v=N`、`style.css?v=N`。
**改了這三個檔，就要把 `N` 加 1**，否則使用者的瀏覽器會繼續用舊快取——
最常見的症狀是「我明明換了後端網址，網站卻還停在離線預覽模式」。
